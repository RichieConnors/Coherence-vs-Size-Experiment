The experiment should be plug and play. The only requirements are having MATLAB and Psychtoolbox installed. http://psychtoolbox.org/download Here is a link to Psychtoolbox download, it has instructions on how to install it.

Other than that you need to find the real life width and height of your screen, and input these in the Setup.m, ScreenWidth and ScreenHeight variables (not width and height). The experiment will still run if you don't change this, but target locations will be wrong.

The experiment can be run from main.m. There is likely some small changes you may have to make to folder locations etc.

More descriptive documentation is in the pdf in the "Documentation" folder.
