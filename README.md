# Coherence-vs-Size-Experiment
This is the main code script which was used to run the coherence vs size experiment.
If there are any questions feel free to email me at richie.connors@icloud.com

The experiment should be plug and play. The only requirements are having MATLAB and Psychtoolbox installed. http://psychtoolbox.org/download Here is a link to Psychtoolbox download, it has instructions on how to install it. Currently, the code is only supported for Windows based systems, and will not automatically run on other systems. 

 **Important notes**
- Vital is you must find the real life width and height of your screen, and input these in the Setup.m as cm, ScreenWidth and ScreenHeight variables (not width and height, which are used for screen resolution). The experiment will still run if you don't change this, but target locations will be wrong and based on one of the predefined screens.

- The experiment can be run from main.m. It could be possible that some changes may need to be made in regards to folder locations.

More descriptive documentation is in the pdf in the "Documentation" folder (work in progress).
